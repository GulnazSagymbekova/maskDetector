# Система распознавания медицинских масок на лицах

## Описание проекта
Данный репозиторий содержит полный конвейер для решения задачи компьютерного зрения по автоматическому определению наличия защитной медицинской маски на лицах людей. Система выполняет бинарную классификацию изображений на две категории: лица в масках и лица без масок. В качестве базовой архитектуры используется метод переноса обучения (Transfer Learning) на базе сверточной нейронной сети MobileNetV2[cite: 6].

## Архитектура и методология
Процесс разработки и обучения модели включает следующие этапы:
1. **Подготовка данных:** Изображения структурированы по папкам классов (`with_mask` и `without_mask`) в соответствии с требованиями для обучения нейросетей[cite: 6].
2. **Перенос обучения (Transfer Learning):** Применение предобученной на наборе данных ImageNet сети MobileNetV2 в качестве мощного экстрактора признаков с замороженными базовыми слоями[cite: 6].
3. **Пользовательский классификатор:** Добавление слоев Global Average Pooling, полносвязных слоев с L2-регуляризацией, слоя Dropout для предотвращения переобучения[cite: 6] и выходного слоя с сигмоидальной функцией активации.
4. **Аугментация данных:** Динамическая генерация измененных вариантов обучающих изображений (повороты, масштабирование, отражения) для повышения устойчивости модели[cite: 6].

## Стек технологий
* **Язык программирования:** Python
* **Библиотека глубокого обучения:** TensorFlow / Keras
* **Обработка изображений:** OpenCV
* **Анализ данных и метрики:** Scikit-Learn, NumPy
* **Визуализация:** Matplotlib
